# 地方議会の会議録（VOICES）

会議録検索システム VOICES で公開されている地方議会の本会議・委員会の会議録を、SQL で検索できるテーブルにしたデータセットです。今は東京都の世田谷区・杉並区の区議会を収録しています。

| テーブル | 内容 |
| --- | --- |
| `minutes.meetings` | 1 行が会議の 1 日分の会議録。議会・会議・会議名・開会日・発言数・会議録の URL |
| `minutes.speeches` | 1 行が 1 発言。議会・開会日・会議名・発言者と発言の本文・発言の URL |

- `meeting_id`（会議録 ID）で 2 つのテーブルを結合できます
- `lg_code`（地方公共団体コード）で議会を絞り込めます
- `speech_order` が 0 の行は、出席者・議事日程などを載せた会議録の冒頭です
- 毎週、各議会の今年と昨年の分を取り直し、まだ無い会議録を追記します
- `speaker` は会議録の表記から空白だけを整えたものです。世田谷区は「石川ナオミ 議長」のように名前と役職を半角スペースでつなぎ、括弧の中の空白は除きます

## 使い方

語を含む発言を新しい順に:

```sql
SELECT assembly, date, meeting_name, speaker, speech_url
FROM gijiroku.minutes.speeches
WHERE speech LIKE '%待機児童%'
ORDER BY date DESC
LIMIT 20;
```

## ビルド

```bash
uv sync
scripts/build.sh
```

取得の間隔は 1 秒です。1 回のビルドで取得するのは各議会の今年から 2 年分（`GIJIROKU_YEARS`）です。すべての年を取得するときは手元で `GIJIROKU_YEARS=0 scripts/build.sh` を実行します。途中で止まったときは、直近 2 年より前の取得済みの年を飛ばして続きから取得します。

## 出典と利用条件

出典：世田谷区議会・杉並区議会の会議録検索システムから取得・加工したものです。

会議録の利用条件は各議会に従います。発言の著作権は各発言者にあり、公開して行われた政治上の演説又は陳述（著作権法 40 条 1 項）などの権利制限規定に当たる場合は許諾なしで利用できます。許諾の要否は利用者が確認してください。
